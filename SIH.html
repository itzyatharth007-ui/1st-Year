About this dashboard

Important: weather data in this browser-only version is live from Open-Meteo. The IoT sensor cards are a simulated streaming layer so the dashboard visibly changes even without hardware. For a real deployment, replace the demo sensor generator with your ESP32/LoRa/MQTT/REST/WebSocket backend.

Auto refresh: weather is refreshed every 60 seconds and the demo telemetry/chart stream changes every 10 seconds.
